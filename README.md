### How I work

- **Reconciliation is a gate, not a slide.** If a slice doesn't add up to the
  headline, the pipeline stops instead of publishing.
- **Data quality is governed, not cleaned up.** Rules are declarative,
  reviewable by non-programmers, and the reason a row was excluded stays
  attached to it.
- **Nothing invented.** What isn't evidenced is labelled unknown — in the code,
  in the report and in the dashboard.
- **The dashboard is the last step, not the first.** Define the question,
  define the numbers, make them trustworthy, model them, *then* visualise.
